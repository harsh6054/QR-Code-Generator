# QR Code Generator Web App

A responsive and interactive QR Code Generator built using **HTML, CSS, and JavaScript**.  
The application allows users to generate QR codes for text or URLs, customize the QR size, and download the generated QR code instantly with a modern user interface.

---

## Features

- Generate QR codes for text or URLs  
- Customizable QR code sizes  
- One-click download functionality  
- Responsive and modern UI design  
- Smooth animations and interactive experience  
- Cross-browser compatibility  

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- QRCode.js Library  

---


## How to Use

1. Clone or download this repository  
2. Open `index.html` in a web browser  
3. Enter text or a URL  
4. Select the desired QR code size  
5. Click **Generate**  
6. Click **Download** to save the QR code
